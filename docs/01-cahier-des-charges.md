# Cahier des charges

## 1. Présentation du projet

Le projet consiste à concevoir et développer une application desktop interne pour une agence de voyage.

L’agence utilise actuellement des fichiers Excel et des documents papier pour gérer les clients, les réservations d’hôtels, les réservations de vols, les paiements et les factures.

L’objectif est de centraliser ces informations dans une application installée sur les ordinateurs de l’agence, avec une base de données partagée.

## 2. Utilisateurs

L’application sera utilisée par :

- Le chef d’agence
- La secrétaire

## 3. Modules principaux

- Authentification
- Gestion des clients
- Gestion des réservations hôtel
- Gestion des réservations vol
- Gestion des paiements
- Génération des factures PDF
- Tableau de bord
- Import CSV/Excel
- Sauvegarde
- Historique des actions
