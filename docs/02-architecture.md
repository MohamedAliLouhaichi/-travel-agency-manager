# Architecture du système

## 1. Type d’application

L’application est une application desktop interne destinée à une agence de voyage.

Elle sera installée uniquement sur les ordinateurs de l’agence.

Elle sera utilisée par :

- Le chef d’agence
- La secrétaire

## 2. Architecture choisie

L’architecture choisie est :

```text
Desktop App -> Backend API -> PostgreSQL Database
```
